# 🌐 Module 1: Introduction to Web Development

Web development refers to the creating, building, and maintaining of websites and web applications that run online on a browser.

---

## What is the World Wide Web (WWW)?

The **World Wide Web** is an interconnected system of public webpages accessible through the Internet. It was invented in 1989 by Sir Tim Berners-Lee.

### Key Components of the Web:

1. **Client (Frontend)**: The user interface that students and users interact with directly in the browser (HTML, CSS, JavaScript).
2. **Server (Backend)**: The computer that processes requests, handles database transactions, and serves webpages.
3. **HTTP / HTTPS**: The protocol (rules) used by browsers and servers to communicate.

---

## Example: A Simple Web Document

Just like in **W3Schools**, here is what a basic web page looks like:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <title>My First Web Page</title>
</head>
<body>
  <h1>Hello, Students!</h1>
  <p>Welcome to Web Systems and Technologies.</p>
</body>
</html>
```
