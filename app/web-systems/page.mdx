# ITE 303: Web Systems and Technologies 2

This course develops advanced full-stack web engineering skills through TypeScript, scalable REST APIs, relational databases, backend security, and reactive user interfaces.

## Current chapter

### [Chapter 2: Scalable REST API Architecture with Express.js](/web-systems/chapter-2)

Build a typed Express server, trace HTTP requests and responses, design RESTful pathways, and separate routes from controllers.

### [Chapter 3: Backend Data Persistence with PostgreSQL](/web-systems/chapter-3)

Begin with a self-paced tutorial that connects the Chapter 2 Student Information API to Supabase PostgreSQL and reads student records through two GET endpoints.
