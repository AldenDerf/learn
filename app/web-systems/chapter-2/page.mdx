# Chapter 2: Scalable REST API Architecture with Express.js

This chapter turns your basic HTTP and TypeScript knowledge into an organized Express API. You will first operate a typed server and trace one request from arrival to response. You will then design predictable REST pathways and separate route definitions from controller and business responsibilities.

## Syllabus outcomes

After completing the chapter, you should be able to:

- orchestrate a Node.js web server and handle standard HTTP request/response parameters;
- describe the HTTP request/response lifecycle and REST constraints;
- design RESTful pathways using architectural separation of concerns; and
- build an Express service using typed routers and controllers.

## Lessons

### [2.1 Server Orchestration & Request/Response Lifecycle](./server-lifecycle)

Learn the jobs of Node.js, TypeScript, and Express; trace middleware and route execution; validate external input; and build a typed dynamic route.

### [2.2 REST Constraints & Architectural Concerns](./rest-architecture)

Learn the six REST constraints, design a clear HTTP resource contract, and organize an Express project into routes, controllers, services, and repositories.

## Laboratory outputs

1. **Lab 2.1:** Initialize a typed Express server with dynamic route handlers and demonstrate successful, invalid, and missing-resource requests.
2. **Lab 2.2:** Separate route paths from controller and business responsibilities while preserving the API contract.

Complete Lesson 2.1 before Lesson 2.2. Each handout includes setup instructions, guided examples, test cases, troubleshooting, an activity, and knowledge checks.
