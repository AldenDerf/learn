# Chapter 3: Backend Data Persistence with PostgreSQL

Start with **[3.1 Connecting Express to Supabase PostgreSQL](./connecting-express-to-supabase-postgresql)**. Extend your Chapter 2 Student Information API so its two GET endpoints read real student rows from Supabase.

Continue with **[3.2 Creating Student Records with POST and PostgreSQL](./creating-student-records-with-postgresql)** to validate JSON requests and save fictional students with a parameterized SQL INSERT.

Next, use **[3.3 Updating Student Records with PUT and PostgreSQL](./updating-student-records-with-put-and-postgresql)** to replace one existing student's editable details and verify the saved row. This lesson is an instructor-review draft. PATCH and DELETE remain future lessons.
