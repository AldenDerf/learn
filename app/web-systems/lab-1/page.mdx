# 🧪 Laboratory 1: Building Your First Web Page

**Subject:** Web Systems and Technologies

**Objective:** Learn how to create a structured HTML5 document and style it with modern CSS.

---

## Instructions

1. Gumawa ng folder sa inyong computer na may pangalang `lab1-lastname`.
2. Sa loob ng folder, gumawa ng dalawang files:
   - `index.html`
   - `style.css`
3. Ipatupad ang sumusunod na specifications sa ibaba.

---

## Deliverables & Specifications

### 1. Requirements ng `index.html`:
- Gamitin ang tamang HTML5 boilerplate (`<!DOCTYPE html>`).
- Maglagay ng Header na may pangalan at student ID mo.
- Maglagay ng Profile Section na may maikling talata tungkol sa iyong sarili.
- Maglagay ng Table ng inyong mga subjects ngayong semester.

### 2. Requirements ng `style.css`:
- Gumamit ng custom Google Font (hal. Inter, Roboto, o Poppins).
- Maglagay ng border at shadow sa inyong profile card.
- Siguraduhing centered ang layout gamit ang Flexbox o CSS Grid.

---

## Example Starter Code

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Lab 1 - Student Profile</title>
  <link rel="stylesheet" href="style.css" />
</head>
<body>
  <div class="card">
    <h1>Juan Dela Cruz</h1>
    <p>BS Information Technology - Year 3</p>
  </div>
</body>
</html>
```
