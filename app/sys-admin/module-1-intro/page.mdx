# 🖥️ Module 1: Introduction to System Administration

System Administration involves the configuration, management, and maintenance of computer systems, multi-user environments, and enterprise servers to ensure high availability and security.

---

## What Does a System Administrator Do?

A **System Administrator (SysAdmin)** is responsible for the upkeep, configuration, and reliable operation of computer systems—especially servers.

### Core Responsibilities:
- **User Account Management**: Adding, modifying, and deleting user accounts.
- **Security & Permissions**: Restricting access to sensitive data and applications.
- **Backup & Recovery**: Formulating and testing disaster recovery strategies.
- **System Monitoring**: Checking server health, CPU/RAM usage, and system logs.

---

## Operating Systems Used in SysAdmin

| Operating System | Common Distributions | Use Case |
| :--- | :--- | :--- |
| **Linux** | Ubuntu Server, Debian, RHEL, Rocky Linux | Web servers, cloud infrastructure, containers |
| **Windows Server** | Windows Server 2022, 2025 | Active Directory, enterprise domain management |
| **Unix / BSD** | FreeBSD, OpenBSD | High-performance networking, firewalls |

---

## Example: Essential SysAdmin Command

Just like in **W3Schools**, let's inspect the first terminal command to check server uptime and resource usage:

```bash
# Check how long the server has been running and current load
uptime

# Check available memory (RAM) in human-readable format
free -h

# Check available storage space on all mounted disks
df -h
```

---

> ⚠️ **Important Reminder:**
> Never execute commands as the `root` superuser unless necessary. Always use `sudo` with caution!
