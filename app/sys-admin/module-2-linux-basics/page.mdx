# 🐧 Module 2: Linux CLI & File System Navigation

In Linux, everything is treated as a file. Navigating the filesystem through the terminal is the most fundamental skill of a System Administrator.

---

## The Linux File System Hierarchy

All files and directories start from the root directory denoted by a single slash `/`.

- `/bin` - Essential binary executable commands (e.g., `ls`, `cat`, `cp`).
- `/etc` - Host-specific system-wide configuration files (e.g., `/etc/passwd`, `/etc/network`).
- `/home` - User personal directories (`/home/student`).
- `/var` - Variable files that change over time, such as server logs (`/var/log`).

---

## Essential CLI Commands (W3Schools Style Cheat Sheet)

| Command | Description | Example |
| :--- | :--- | :--- |
| `pwd` | Print Working Directory (shows current path) | `pwd` |
| `ls -la` | List all files including hidden ones with details | `ls -la /var/log` |
| `cd` | Change directory | `cd /etc/nginx` |
| `mkdir -p` | Create a new directory and parent directories | `mkdir -p projects/lab1` |
| `cp -r` | Copy files or directories recursively | `cp -r source/ dest/` |
| `rm -rf` | Remove file or directory recursively *(Caution!)* | `rm -rf temp/` |

---

## Example: Terminal Session

```bash
# Display your current username
whoami

# View directory contents with human-readable file sizes
ls -lh

# View the last 20 lines of system authentication log
sudo tail -n 20 /var/log/auth.log
```

---

> ⚠️ **Warning:**
> Always double check your path before running destructive commands like `rm -rf`!
