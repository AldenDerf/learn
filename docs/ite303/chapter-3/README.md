# Chapter 3 — Backend Data Persistence with PostgreSQL

The first student-facing lesson is [3.1 Connecting Express to Supabase PostgreSQL](01-connecting-express-to-supabase-postgresql.mdx). It is written for about 90–120 minutes of self-paced Saturday work. It extends the Chapter 2 Student Information API with read-only PostgreSQL access.

The second lesson, [3.2 Creating Student Records with POST and PostgreSQL](02-creating-students-with-postgresql.mdx), takes 90–120 minutes. It extends the same API with a database-backed POST handler. [3.3 Updating and Deleting Student Records (PUT & DELETE)](03-updating-student-records-with-put-and-postgresql.mdx) is one instructor-review draft with concepts, guided code, Postman and Supabase tests, and submission requirements. It updates and removes fictional rows in the same Student API and Supabase project while retaining GET and POST. A thin route wrapper imports the canonical MDX; the former discussion URL points readers to it. Chapter 3.4 will cover complete CRUD integration and testing; PATCH remains optional. See [instructor notes](instructor-guide.md).
