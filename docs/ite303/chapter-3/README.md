# Chapter 3 — Backend Data Persistence with PostgreSQL

The first student-facing lesson is [3.1 Connecting Express to Supabase PostgreSQL](01-connecting-express-to-supabase-postgresql.mdx). It is written for about 90–120 minutes of self-paced Saturday work. It extends the Chapter 2 Student Information API with read-only PostgreSQL access.

The second lesson, [3.2 Creating Student Records with POST and PostgreSQL](02-creating-students-with-postgresql.mdx), takes 90–120 minutes. It extends the same API with a database-backed POST handler. Chapter 3.3 now has a [Wednesday concept discussion](03a-crud-update-delete-concepts.mdx) for two hours and a [Saturday PUT and DELETE lab](03-updating-student-records-with-put-and-postgresql.mdx) for three hours. Both are instructor-review drafts. The lab updates and removes fictional rows in the same Student API and Supabase project while retaining GET and POST. Canonical MDX files are imported by thin route wrappers under `app/web-systems/chapter-3`. Chapter 3.4 will cover complete CRUD integration and testing; PATCH remains optional. See [instructor notes](instructor-guide.md).
