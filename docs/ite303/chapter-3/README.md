# Chapter 3 — Backend Data Persistence with PostgreSQL

The first student-facing lesson is [3.1 Connecting Express to Supabase PostgreSQL](01-connecting-express-to-supabase-postgresql.mdx). It is a new draft for instructor review, written for about 90–120 minutes of self-paced Saturday work. It extends the Chapter 2 Student Information API with read-only PostgreSQL access.

The second lesson, [3.2 Creating Student Records with POST and PostgreSQL](02-creating-students-with-postgresql.mdx), is a new instructor-review draft for 90–120 minutes. It extends the same API with a database-backed POST handler and Lab 3.2. Both canonical lessons are imported by thin route wrappers under `app/web-systems/chapter-3`. Database-backed updates and deletes are not yet authored. See [instructor notes](instructor-guide.md).
